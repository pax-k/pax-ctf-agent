# Example Strix instructions

Read `SCOPE.md` before any test. State the selected operating mode. Test only
the exact authorized assets and actions. Do not access third-party systems,
exfiltrate secrets, create persistence, deny service, or delete evidence.

Stop when target identity, authorization, scope, or impact is uncertain. Keep
findings and evidence under this engagement directory. Record the asset, lane,
tool, timestamp, validation state, evidence path, and original source for each
result.
